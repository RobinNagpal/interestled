Installing it

  1. Tap the button. Your browser downloads the file.
  2. Tap the download when it finishes, and confirm Install.
  3. The first time, Android asks whether this browser may install apps. Allow it, then tap the download again.

On a computer? Point a phone camera at this to open interestled.com/android-install.

This build is signed with a test key, so it will not update over a copy installed from anywhere else, and Android will call it an app from an unknown source. That is expected while Interest Led is not in the Play Store.

iPhone builds are not published here yet. Use the web app in the meantime.
